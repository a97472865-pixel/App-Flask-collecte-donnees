# App-Flask-collecte-donnees
# 📊 SmartSurvey Analytics

# I- Présentation du projet

SmartSurvey Analytics est une application web de collecte et d’analyse descriptive de données développée avec **Python (Flask)** et **R**.

L’objectif principal du projet est de permettre la collecte d’informations sur les habitudes numériques des étudiants universitaires, puis d’effectuer une analyse statistique et visuelle des données recueillies.

Le projet combine :
- un système de collecte via formulaire web,
- une base de données SQLite,
- un export CSV,
- des analyses statistiques avec R,
- des visualisations graphiques.

---

# II- Objectifs du projet

- Collecter des données utilisateurs via une interface web
- Stocker les données dans une base SQLite
- Exporter les données au format CSV
- Réaliser des analyses descriptives avec R
- Générer des graphiques statistiques
- Préparer une base évolutive pour des dashboards et analyses avancées
